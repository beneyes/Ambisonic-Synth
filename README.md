# Ambisonic Synth
Ambisonic Synth Max Patch

Open ambisonicsynthproject.maxpat

Load wav files into the file window by dragging and dropping.

The sound is immediately bookend up into 8 objects which can be mapped to an LFO matrix to modulate panning in 3d space!

Select loop point by dragging across the wav file

Setup LFOs by pressing the cross and selecting the speed 

In the matrix route the LFO to XYZ of the sound object
